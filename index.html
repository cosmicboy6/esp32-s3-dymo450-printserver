DYMO LabelWriter 450 → ESP32-S3 Print Server

Turn a USB-only LabelWriter 450 into a network printer, reachable on hostname:9100, and discoverable over mDNS as a DYMO LabelWriter 450.

Connect a blank ESP32-S3 board over USB, then press Install. The installer talks to the board directly through your browser (Web Serial) — nothing is uploaded anywhere.

Browser doesn't support Web Serial — use Chrome, Edge or Firefox on a desktop. Open this page over https:// to install.
Board requirement: ESP32-S3 with 16 MB flash + 8 MB octal PSRAM (e.g. ESP32-S3-DevKitC-1 N16R8). The prebuilt image is compiled for that exact target. For any other board, build from source instead.

After flashing

  1. The device boots with no WiFi credentials, so it starts its fallback access point:
    SSID DYMO Print Fallback  /  Password dymosetup
  2. Join that network, then open http://192.168.4.1 (captive portal) and enter your real WiFi details.
  3. Find the device on your network (mDNS dymo-labelwriter-450.local); it advertises itself as a DYMO LabelWriter 450 raw printer. Add it to Home Assistant using the API encryption key 9GXBCDmqW1uiTOdRJC60k8qvZ9W/yYW0jiE3xV/obGc=.
  4. Point the DYMO software (or CUPS) at the raw port:
    lpadmin -p DYMO450 -E -v socket://dymo-labelwriter-450.local:9100 -m <LW450 driver>
  5. Print a quick test label straight from the browser at http://<device>/print — one line, drawn large (up to 20 characters) in the same bold font as a normal label, with a Print label button.
The prebuilt image intentionally contains no personal secrets (placeholder WiFi, publicly documented API key). To bake in your own credentials, build from source — see the README.
